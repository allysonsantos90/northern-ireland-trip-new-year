# Northern Ireland Escape — New Year 2026/27

Arquivos do site para publicação no GitHub Pages.

## Arquivos
- `index.html` — estrutura e conteúdo do site.
- `styles.css` — identidade visual, layout responsivo e novo desenho do roteiro.
- `script.js` — tradução PT/EN, carrossel, cópia do resumo e compartilhamento no WhatsApp.

## Como atualizar no GitHub
1. Abra o repositório `northern-ireland-trip-new-year`.
2. Entre na raiz do repositório.
3. Faça upload dos três arquivos (`index.html`, `styles.css` e `script.js`) e confirme a substituição.
4. Aguarde alguns minutos para o GitHub Pages publicar as alterações.
5. Atualize o site no navegador. Se necessário, faça uma atualização forçada ou abra em janela privada.

## Melhorias desta versão
- Roteiro apresentado em cartões por dia, com data e rótulos visuais.
- Resumo dos quatro dias no início da seção.
- Dia 31/12 destacado, com sequência visual das quatro paradas e indicação de Carrick-a-Rede como opcional.
- Aviso sobre poucas horas de luz no inverno.
- Detalhes práticos de chegada, check-in, compras, dia flexível e retorno.
- Navegação visível também em telas pequenas.
- Layout adaptado para celular.
- Traduções PT/EN atualizadas para os novos elementos.

## Observações
A hospedagem ainda não foi escolhida. Por isso, o site não fixa um ponto de partida nem apresenta tempos de deslocamento como definitivos. As imagens são carregadas de URLs externas do Wikimedia Commons; verifique se continuam disponíveis antes da viagem.
