# Northern Ireland Escape — New Year 2026/27

Pacote completo do site para publicar no GitHub Pages.

## Arquivos
- `index.html` — página completa com hero, destinos, roteiro visual por dia, mapa e informações práticas.
- `styles.css` — identidade visual, cartões panorâmicos e layout responsivo.
- `script.js` — tradução português/inglês, carrossel, cópia do resumo e compartilhamento no WhatsApp.

## Como publicar
1. Abra o repositório `allysonsantos90/northern-ireland-trip-new-year`.
2. Na raiz, substitua os arquivos `index.html`, `styles.css` e `script.js` pelos deste pacote.
3. Não envie o ZIP dentro do site; extraia os arquivos primeiro.
4. Aguarde o GitHub Pages publicar e atualize o navegador.

## Observações
A hospedagem ainda não foi definida. As referências de distância e tempo usam Belfast como base quando necessário e não são garantias. Recalcule as rotas após escolher a hospedagem. As imagens são carregadas de URLs externas do Wikimedia Commons e podem mudar de disponibilidade.
